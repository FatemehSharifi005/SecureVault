# SecureVault

SecureVault is an educational file encryption and decryption tool written in C.

## Features

- Caesar Cipher encryption and decryption
- XOR Cipher encryption and decryption
- File-based encryption and decryption
- User-defined encryption keys
- Separate encrypted and decrypted output files

## Algorithms

### Caesar Cipher

A classical substitution cipher that shifts alphabetic characters based on a key.

### XOR Cipher

A simple symmetric encryption technique based on the XOR operation.

## Technologies

- C
- Standard C Library
- File I/O

## How to Run

Compile the program using GCC:

gcc SecureVault.c -o SecureVault

Then run:

./SecureVault
